# Singapore Soft City Guide

一个可直接分享的新加坡旅行导览小站。

## 打开方式

直接打开 `index.html` 即可浏览。页面会读取同目录下的 `styles.css` 和 `app.js`。

## 发布方式

把 `index.html`、`styles.css`、`app.js` 和 `assets/` 文件夹放到任意静态网站托管服务即可，例如 GitHub Pages、Netlify、Vercel 或 Cloudflare Pages。

本仓库已包含 GitHub Pages 工作流：推送到 `main` 后会自动发布静态站点。发布地址通常是：

`https://outmankung.github.io/singapore-soft-city-guide/`

## 出发前复核

票务、营业时间和演唱会入场规则可能变化。建议在 2026-09-23 左右再复核页面底部的官方入口。
